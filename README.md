## Responsive layout

The Node.js site uses fluid grids and wrapping content for phones, tablets, and
desktop displays, retaining the existing theme and colors. Navigation switches
to a keyboard-accessible menu below 1024px. The homepage festival feature stacks
below 900px, and galleries use viewport-bounded image dialogs for portrait and
landscape viewing. Interactive controls support touch and keyboard input.

When changing content or styles, check narrow screens (320px), tablet portrait
and landscape, desktop, and wide displays. Keep grid minimums bounded by `100%`
and allow long addresses and email addresses to wrap rather than hiding overflow.
